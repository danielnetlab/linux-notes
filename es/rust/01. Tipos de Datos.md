## 01.01 Definición
Un **tipo de dato** define:
- qué clase de valor es algo
- cuánta memoria ocupa
- qué operaciones están permitidas
- cómo debe tratarlo el compilador
No es lo mismo un número que un texto, ni un número con decimales que un número sin decimales. Rust **necesita saber esto con exactitud.**
---
## 01.02 Rust es estáticamente tipado
Rust **siempre exige que el tipo sea conocido en compilación;** si no puede inferirlo, el código es inválido hasta que lo anotes. En otros casos, Rust puede necesitar el contexto de uso para inferir el tipo.
``` rust
let x = 5;
let y = x + 3;
println!("Juan tiene {y} nueces");
```
Rust deduce:
- `5` -> entero
- entero por defecto -> `i32`
---
## 01.03 Inferencia de tipos
Rust **deduce el tipo automáticamente cuando no hay ambigüedad**.
``` rust
let a = 10      // i32
let b = 3.14    // f64
let c = true    // bool
```
---
## 01.04 Anotación explícita
A veces **Rust no puede adivinar**.
### Cuando hay **ambigüedad**.
``` rust
let n = "65".parse();
```
- Rust piensa:
	- "¿`i32`? ¿`u8`? ¿`i64`? ¿Un minotauro?"
### Cuando el valor viene de fuera.
``` rust
let edad: u8 = input.parse().unwrap();
```
- Rust piensa:
	- **Sin tipo** -> error.
	- Con tipo -> paz interior 🧘‍♂️.
### Cuando usas `const`.
``` rust
const MAX: i32 = 120;
```
- Rust aclara:
	- se evalúa en **tiempo de compilación**
	- debe ser **100% explícito**
	- no admite suposiciones
---
## 01.05 Inferencia de tipos *vs* anotación explícita
Las variables **siempre tienen tipo**. La diferencia es **quién lo decide**:
- **el compilador** -> inferencia
- **tú** -> anotación explícita
---
## 01.06 Dos grandes grupos de tipos
Rust divide los tipos en dos categorías:
- **Tipos escalares** -> un solo valor
- **Tipos compuestos** -> varios valores juntos
---
# 01.07 Tipos de escalares
---
## 01.07.01 Enteros
### Enteros con signo (`i`)
Pueden ser positivos o negativos:
``` rust
let x: i32 = -68;
```
### Enteros sin signo (`u`)
Solo pueden ser cero o positivos
``` rust
let y: u32 = 68;
```
---
### Tamaños disponibles
| Tipo            | Qué significa             |
| --------------- | ------------------------- |
| `i8/u8`         | 8 bits                    |
| `i16`/`u16`     | 16 bits                   |
| `i32`/`u32`     | 32 bits (default)         |
| `i64`/`u64`     | 64 bits                   |
| `i128`/`u128`   | 128 bits                  |
| `isize`/`usize` | tamaño de la arquitectura |

Usa `i32` por defecto, usa `usize` para índices y tamaños, usa `u*` solo si **nunca** habrá negativos.

---
## 01.07.02 Literales numéricos
Rust permite escribir números en varias bases:
``` rust
let decimal = 98_222;
let hex     = 0xff;
let octal   = 0o77;
let binario = 0b1111_0000;
let byte    = b'A';
```
- `_` solo mejora la lectura
- `b'A'` es un **byte (`u8`)**, no un `char`
---
## 01.07.03 Overflow de enteros
Ocurre cuando intentas guardar en una variable un número **más grande de lo que este tipo puede representar**.
``` rust
let x: u8 = 255;
let y = x + 1;
```
- `u8` = entero **sin signo** de 8 bits
- Rango válido: **0 a 255**
- `255` ya es el **máximo**
- Sumar `+1` es como intentar meter agua extra en un vaso lleno: **no cabe**.

## 01.07.04 Modo Debug
Es una forma de **compilar** un programa en Rust, cuando se usa `cargo run` se está utilizando ***Debug***. Sirve para.
- Para **aprender**
- Para **detectar errores**
- Para que el programa **falle fuerte y pronto**
---
## 01.07.05 Modo Release
Es otra manera de **compilar**, se utiliza usando `cargo run --release`. Sirve para:
- **Ya funciona**
- Va a **producción**
- Necesita **máximo rendimiento**
---
## 01.07.06 Números decimales
Los decimales en Rust son `f32` y `f64`. Por defecto es `f64`.
``` rust
let x = 2.0;   // f64 por defecto
let y: f32 = 3.0;
```
`f32`
- 32 bits
- Menos precisión
- Más rápido
- Más errores de redondeo
`f64`
- 64 bits
- Más precisión
- Más estable
- **Recomendado por defecto**
---
## 01.07.07 Booleanos (`bool`)
Los valores lógicos se llaman **booleanos** y solo hay 2 valores `true` y `false`.
``` rust
let activo = true;
let terminado: bool = false;
```
---
## 01.07.08 Caracteres (`char`)
Representa un **carácter Unicode**, no un byte, siempre ocupa **4 bytes**.
``` rust
let a = 'a';    // char (4 bytes)
let x = "a";    // &str (texto)
```

# 01.08 Tipos compuestos
---
## 01.08.01 Tuplas
Una **tupla** es una forma de **agrupar varios valores en una sola variable**, incluso si **son de tipos distintos**.
``` rust
let datos = (52, 1.67, 'F');
```
- `52` -> entero
- `1.67` -> decimal
- `'F'` -> carácter
### Acceso por índice
Cada valor tiene una **posición fija**, empezando por **0**.
``` rust
let edad = datos.0;
```
- `.0` -> primer valor
- `.1` -> segundo
- ...
### Destructuración
Puedes "romper" la tupla en variables individuales:
``` rust
let (edad, altura, inicial) = datos;
```
### ¿Para qué se usan?
1. Devolver varios valores de una función
``` rust
fn calcular() -> (i32, f64) {
	(30, 1.80)
}
```
2. Agrupar datos pequeños relacionados
	- no merece la pena crear un `struct`
	- los datos van juntos
	- el significado es obvio
``` rust
let coordenadas = (10, 20.54);
```
- `10` -> `i32`
- `20.54` -> `f64`
### Cuándo no usarlas
Si tienes:
- muchos campos
- datos complejos
- significado poco claro
Entonces **usa una** `struct`.
---
## 01.08.02 Arrays
Una colección de:
- valores **del mismo tipo**
- con **tamaño fijo**
- guardados de forma **contigua en memoria**
``` rust
let numeros = [1, 2, 3, 4, 5];
```
- tipo -> `i32` (inferido)
- tamaño -> `5`
- índices -> `0` a `4`
### Tipo explícito
Si quieres ser claro (o el compilador lo exige):
``` rust
let numeros: [u32; 5] = [1, 2, 3, 4, 5];
```
- *"array de **5** enteros `i32`*
### Acceso a elementos
Se accede usando **índices**:
``` rust
let primero = numeros[0];
```
### Acceso fuera de rango
Esto **no se perdona**:
``` rust
let x = numeros[10]; // panic
```
