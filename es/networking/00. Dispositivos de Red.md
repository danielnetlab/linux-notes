## 00.01 Definición - Red De Computadoras
Conjunto de dispositivos interconectados que permite el intercambio de datos y el uso compartido de recursos. 
Los datos son **información** que se transmite por la red. Los datos **se envían y se reciben**.
- Archivos (PDF, imágenes, vídeos)
- Correos electrónicos
- Mensajes
- Paquetes que viajan por Internet
- Peticiones y respuestas (HTTP, DNS, etc.)
Los recursos son **elementos o servicios** que la red permite **usar o compartir**. Los recursos **se utilizan**, no solo se envían.
- Impresoras en red
- Servidores (web, archivos, correo)
- Almacenamiento compartido
- Conexión a Internet
- Aplicaciones o servicios en red

## 00.02 Definición - Nodos
Dispositivos que se conectan a una red y participan en la comunicación.
- **routers** -> Dispositivo de red que conecta diferentes redes entre sí, dirigiendo paquetes de datos eligiendo la mejor ruta
- **switches** -> Dispositivo de red que interconecta dispositivos dentro de una misma red y envía los datos solo al destino correcto.
- **firewalls** -> Dispositivo o sistema de seguridad que controla y filtra el tráfico de red según reglas definidas.
- **servidores** -> Dispositivo o sistema que proporciona servicios, recursos o datos a otros dispositivos de la red.
- **clientes** -> Dispositivo o sistema que solicita o utiliza los servicios, recursos o datos proporcionados por un servidor.
Los servidores y clientes también se denominan **end hosts** o **endpoints**.

## 00.03 Servidores y clientes
Cuando un dispositivo (por ejemplo, una PC) solicita archivos a otro, **el que hace la solicitud actúa como cliente** y **el que responde enviando los archivos actúa como servidor**.
![[01.svg]]
Igual pasa con todos los servicios que conocemos "Youtube, DuckduckGo, NextDNS, etc.". Sin embargo, los servicios envían los datos por partes, según se van solicitando "ver un vídeo, una búsqueda, etc.".

## 00.04 Switches
Un switch (conmutador) es un dispositivo de red que conecta varios dispositivos dentro de una red local (LAN), y se encarga de enviar los datos únicamente al dispositivo de destino correcto, usando direcciones MAC. 
![[03.svg]]
Los switches tienen múltiples puertos de red para que los dispositivos finales (hosts), como las PCs, se conecten dentro de una red local (LAN).
Para que exista comunicación entre redes distintas a través de Internet, es necesario otro dispositivo de red: el router (enrutador).
Por ejemplo, si un dispositivo de la sucursal de New York necesita documentos almacenados en la red de India, los routers se encargan de enviar los datos entre ambas redes.
**El switch conecta dispositivos; el router conecta redes e internet.**

## 00.05 Firewalls
Un firewall es un dispositivo o sistema de seguridad que controla y filtra el tráfico de red entrante y saliente según un conjunto de reglas de seguridad, con el objetivo de proteger los dispositivos internos de una red.
### Network firewalls
Puede estar integrado en un router o funcionar como un dispositivo independiente. Se encarga de filtrar el tráfico de red según reglas de seguridad y decide qué tráfico se permite y cuál se bloquea.
![[05.svg]]
### Host-based firewalls
Son firewalls de software que filtran el tráfico que entra y sale de un dispositivo específico (host), como una PC, La mayoría de los sistemas operativos incluyen un firewall como línea de defensa adicional.
![[06.svg]]
**El firewall de red protege la red completa; el firewall de host protege un solo dispositivo.**
